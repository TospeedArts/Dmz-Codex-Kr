# DMZ Codex 한글 지도 (MW4 하진)

https://dmzcodex.com/map/ 과 https://dmzcodex.com/locations/ (및 하위 주소)의 영문 지명·마커·메뉴를 한글로 바꿔 보여주는 크롬 확장 프로그램입니다.
공식 한국어 블로그(callofduty.com/ko)의 지명 표기를 우선 사용합니다.

## 설치 (개발자 모드)

1. 이 폴더(`dmz-hangul`)를 압축 해제해 둡니다.
2. 크롬 주소창에 `chrome://extensions` 입력
3. 우측 상단 **개발자 모드** 켜기
4. **압축해제된 확장 프로그램을 로드합니다** → `dmz-hangul` 폴더 선택
5. https://dmzcodex.com/map/ 또는 /locations/ 를 열면 자동으로 한글화됩니다.

툴바 아이콘을 누르면 설정을 바꿀 수 있습니다.
- 한글로 보기 on/off
- 비공식 번역 포함 (끄면 공식 표기만 적용)
- 미번역 문구 수집 (아이콘 클릭 설명 중 번역 안 된 영문을 모아 복사)

## 전리품 페이지 (v1.7)

`dmzcodex.com/sector/loot/` 등 사이트 전체(영어 페이지)에서 동작합니다. (fr/de/it/es/ar 페이지는 제외) 카테고리 이름, 설명 문구, 아이템 이름(약 250개)을 사전에 넣었습니다.
열쇠 이름은 기존 공식 번역을 그대로 쓰고, 그 외 아이템 이름은 공식 표기를 확인하지 못해 비공식(`x`)입니다.
한글로 검색하면 화면 오른쪽 아래에 "🔎 영문 검색어: Backpack" 처럼 변환된 검색어가 잠깐 표시됩니다. 표시가 안 나오면 변환이 안 된 것이고, 표시는 나오는데 결과가 없으면 사이트 검색 쪽 문제입니다.
콘솔에서 `__dmzkoConvert("배낭")` 으로 변환 결과를 직접 확인할 수도 있습니다.
한글 검색이 안 될 때는 페이지에서 F12 → Console 에 `localStorage.dmzkoDebug="1"` 을 입력하고 새로고침한 뒤 검색해 보세요. 변환된 영문 검색어가 콘솔에 찍힙니다.

## 한글 검색 (v1.5)

사이트 검색은 내부 영문 데이터로 찾기 때문에 화면만 한글로 바꿔서는 한글로 검색되지 않습니다.
그래서 검색창에 한글을 입력하면 사이트가 값을 읽는 순간에 영문으로 바꿔 전달합니다. (화면에는 입력한 한글이 그대로 보임)

- 예: `열쇠` → Key, `창산` → Chang-san Air Base, `주유소` → Gas Station, `암시장 열쇠` → Black Market Weapons Locker Key
- 변환은 `dictionary.js` 의 쌍을 거꾸로 사용하므로, 사전에 한글이 있는 항목만 검색됩니다.
- 안 되는 단어는 사전에 한 줄 추가하면 됩니다.
- 팝업의 **한글 검색** 으로 켜고 끌 수 있습니다. (Chrome 111 이상 필요)

## 아이콘 클릭 설명 번역

지도 아이콘을 눌렀을 때 나오는 설명 문장은 **문장이 통째로 사전과 같을 때만** 번역됩니다(등급 `x`).
이미 위치 페이지 설명 약 70개와 서비스 설명이 들어 있고, 사전에 없는 문장은 영문으로 남습니다.
(비공식 번역이라 팝업에서 '비공식 번역 포함'을 꺼야 하는 경우엔 설명은 번역되지 않습니다.)

빠진 문장 채우는 법
1. 팝업에서 **미번역 문구 수집**을 켜고 페이지를 새로고침
2. 번역 안 된 설명이 나오는 아이콘(또는 페이지)을 열어 본다
3. 팝업의 **수집한 문구 복사** → `dictionary.js` 의 "여기에 직접 추가하세요" 아래에 붙여넣기
4. 붙여넣은 줄의 두 번째 칸(`""`)에 한글을 채운다

## 위치 페이지 (/locations/)

- 목록 화면의 필터·카드 문구, 위치 상세 페이지의 제목·라벨은 번역되어 있습니다.
- 상세 페이지의 **본문 설명 문단**은 위치마다 길고 달라서, 사전에 있는 문장만 번역됩니다.
  빠진 부분은 위의 "빠진 문장 채우는 법"과 같은 방식으로 모아서 추가하세요.
- 사이트의 다른 주소(가이드 등)에서도 쓰려면 `manifest.json` 의 `matches` 에 주소를 추가하면 됩니다.
  예) `"https://dmzcodex.com/guides/*"`

## 링크가 섞인 문장

문장 중간에 링크(노란 글씨)가 있으면, 링크 자리를 `{1}`, `{2}` 로 적어 문장 전체를 등록합니다.
(미번역 문구 수집을 켜면 이런 문장도 `{1}` 형태로 모입니다.)

    ["The inner {1} is ringed by a tall wall.", "{1} 내부는 높은 벽으로 둘러싸여 있습니다.", "x"],

한글 쪽 `{1}`, `{2}` 는 영문과 같은 순서로 모두 넣어야 합니다. 링크 자체의 글자는 따로 번역됩니다.

## 화살표(→)가 붙은 문구 (v1.7.6)

`Radiation Station →` 처럼 글자 앞/뒤에 화살표가 붙어 있으면, 화살표를 떼고 본문(`Radiation Station`)만 사전에서 찾은 뒤 화살표를 다시 붙입니다.
그래서 사전에는 화살표 없이 이름만 등록하면 됩니다. (기존의 `"Open map →"` 처럼 화살표까지 넣은 항목도 그대로 동작)

## 사전 수정·추가

`dictionary.js` 맨 아래 "여기에 직접 추가하세요" 부분에 한 줄씩 추가하면 됩니다.

    ["영문 이름", "한글 이름", "o"],

등급: `o` 공식 / `u` 비공식(부분 일치) / `x` 비공식(문장 전체가 같을 때만)

수정 후 `chrome://extensions` 에서 확장 프로그램의 새로고침(↻) 버튼을 누르고 지도 페이지를 새로고침하세요.

## 한계

- 지도 배경 이미지(`hajin-2048.webp`)에 들어 있는 글자는 이미지라서 바꿀 수 없습니다.
- 사이트가 장소·키룸을 추가하거나 이름을 바꾸면 사전에 없는 항목은 영문으로 남습니다.
- 공식 한글 표기를 확인하지 못한 고유명사(예:일부 키룸·NPC 이름, 스토리 임무명)는 번역하지 않고 영문 그대로 둡니다.
